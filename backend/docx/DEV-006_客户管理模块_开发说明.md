## 4. 核心类说明

### 4.1 CrmCustomerServiceImpl
- **分页查询**: LambdaQueryWrapper 动态条件，支持 9 个查询字段 + 时间范围
- **名称查重**: CrmCustomerMapper.countByName / countByNameExcludeId 直接 SQL
- **owner 校验**: 查询 sys_user 确认存在、未删除、启用
- **类型转换**: DB level 为 VARCHAR，API 为 Integer，Service 层转换
- **删除/状态**: 使用 LambdaUpdateWrapper.set() 强制设置字段（避免 @TableLogic 剥离问题）

### 4.2 CustomerPermissionInterceptor
- **拦截路径**: `/api/v1/customer/customers/**`
- **允许角色**: ADMIN, SALES
- **逻辑**: 优先使用 LoginUserContext 缓存角色，无缓存时查询数据库
- **拒绝**: 抛出 BusinessException(FORBIDDEN, "No permission to access")

### 4.3 CrmCustomerMapper
- 继承 BaseMapper<CrmCustomer>
- countByName: 新增时名称查重
- countByNameExcludeId: 修改时名称查重（排除自身）

## 7. 客户管理业务规则

- customerName 必填，在 deleted=0 中唯一
- ownerId 必填，必须对应存在+启用+未删除的用户
- level: 1-5（DB 存 VARCHAR，API 传 Integer）
- status: 0无效/1有效/2公海
- score: 0-100
- 删除: 逻辑删除，LambdaUpdateWrapper 强制更新
- created_by/updated_by 自动设置为当前登录用户
- 列表/详情返回 ownerName

## 8. 权限控制说明

```
请求 /api/v1/customer/customers
  → JwtAuthenticationFilter（验证 Token → userId/username）
    → CustomerPermissionInterceptor.preHandle()
      1. 获取当前用户角色（优先缓存，无则查 DB）
      2. 检查是否有 ADMIN 或 SALES
      3. 无 → throw BusinessException(FORBIDDEN, "No permission to access")
      4. 有 → 放行

系统管理: /api/v1/system/** → AdminInterceptor → 只有 ADMIN
客户管理: /api/v1/customer/** → CustomerPermissionInterceptor → ADMIN 或 SALES
```

## 11. curl 测试命令

```bash
# 0. 变量
TOKEN="<admin-token>"
SALES_TOKEN="<sales01-token>"

# 1. 新增客户

  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $TOKEN" \
  -d '{"customerName":"Test Company Ltd","industry":"Software","source":"Website","level":3,"region":"Beijing","address":"Haidian","contactName":"Alice","contactPhone":"13800000001","contactEmail":"alice@test.com","ownerId":2,"status":1,"score":80}'

  -H "Authorization: Bearer $TOKEN"

  -H "Authorization: Bearer $TOKEN"

# 4. 修改客户
curl -X PUT http://localhost:8080/api/v1/customer/customers/1 \
  -H "Content-Type: application/json" \

  -d '{"customerName":"Test Company Updated","level":4,"score":90,"remark":"Updated"}'

  -H "Authorization: Bearer $TOKEN" \
  -d '{"status":2}'

# 9. 无 Token → 401
curl "http://localhost:8080/api/v1/customer/customers?pageNo=1&pageSize=10"
```

## 12. 常见失败场景

| 场景 | 预期 |
|------|------|
| 新增重复名称 | DUPLICATE_KEY "Customer name already exists" |
| ownerId 不存在 | PARAM_ERROR "Owner user not found" |
| owner 被禁用 | PARAM_ERROR "Owner user is disabled" |
| level 超出 1-5 | PARAM_ERROR "Level must be 1-5" |
| status 不是 0/1/2 | PARAM_ERROR "Status must be 0/1/2" |
| score 超出 0-100 | PARAM_ERROR "Score must be 0-100" |
| 无 Token | 401 |
| 非 ADMIN/SALES | 403 |
| 查询不存在客户 | DATA_NOT_FOUND "Customer not found" |
