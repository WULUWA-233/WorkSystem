## 13. 如何验证接口仍可用

```bash
TOKEN=$(curl -s -X POST http://localhost:8080/api/v1/auth/login -H "Content-Type: application/json" -d '{"username":"admin","password":"123456"}' | grep -o '"accessToken":"[^"]*"' | cut -d'"' -f4)
curl http://localhost:8080/api/v1/common/health
curl -H "Authorization: Bearer $TOKEN" "http://localhost:8080/api/v1/system/users?pageNo=1&pageSize=5"
curl -H "Authorization: Bearer $TOKEN" "http://localhost:8080/api/v1/analytics/overview"
```
