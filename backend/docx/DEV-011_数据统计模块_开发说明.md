## 4. 核心类说明

### AnalyticsMapper
- 12 个 @Select 聚合 SQL，使用 MyBatis 动态 SQL `<if>` 处理可选时间范围
- Map<String,Object> 返回，Service 层做类型转换

### AnalyticsServiceImpl
- 概览：一次调用 11 个聚合查询
- 趋势：DATE_FORMAT + day/month 动态 fmt + 时间范围
- 阶段/状态分布：预设全 0 结构 + 填充实际数据
- 销售业绩：sys_user 为主表 + 子查询统计 4 个业务表

## 7. 统计口径

- 所有统计默认 `deleted = 0`
- 金额: BigDecimal，无数据返回 0
- 空字符串行业/地区 → "Not filled"
- 阶段名/状态名: 中英文对照硬编码
- 时间范围: startTime <= created_at <= endTime

## 8. 权限控制

`/api/v1/analytics/**` → CustomerPermissionInterceptor → ADMIN/SALES
