## 7. 跟进记录业务规则

- customerId 必填，需存在+未删除
- opportunityId 可选；若有，需存在+未删除+其customer_id等于customerId
- followType 必填（字符串，不强制字典）
- followContent 必填
- customerIntention 可选，范围 1-4（低/中/高/强烈）
- followTime 未传默认当前时间
- 新增后更新客户 last_follow_time=followTime, next_follow_time=nextFollowTime
- 新增后更新商机 last/next_follow_time（如关联）
- 删除为逻辑删除，不回滚客户/商机的 follow_time

## 11. curl 测试命令

```bash
TOKEN="<admin-token>"

# 1. 新增客户跟进
curl -X POST http://localhost:8080/api/v1/customer/follow-records \
  -H "Content-Type: application/json" -H "Authorization: Bearer $TOKEN" \
  -d '{"customerId":1,"followType":"Phone","followContent":"Discussed requirements","followResult":"Positive","customerIntention":3,"followerId":2,"followTime":"2026-06-24 15:30:00","nextFollowTime":"2026-06-30 10:00:00"}'

# 2. 新增商机跟进
curl -X POST http://localhost:8080/api/v1/customer/follow-records \
  -H "Content-Type: application/json" -H "Authorization: Bearer $TOKEN" \
  -d '{"customerId":1,"opportunityId":1,"followType":"Meeting","followContent":"Demo completed","followResult":"Client interested","customerIntention":4,"followerId":2}'

# 3. 跟进分页
curl "http://localhost:8080/api/v1/customer/follow-records?pageNo=1&pageSize=10" -H "Authorization: Bearer $TOKEN"

# 4. 跟进详情
curl http://localhost:8080/api/v1/customer/follow-records/1 -H "Authorization: Bearer $TOKEN"

# 5. 按客户查跟进
curl "http://localhost:8080/api/v1/customer/customers/1/follow-records?pageNo=1&pageSize=10" -H "Authorization: Bearer $TOKEN"

# 6. 按商机查跟进
curl "http://localhost:8080/api/v1/sales/opportunities/1/follow-records?pageNo=1&pageSize=10" -H "Authorization: Bearer $TOKEN"

# 7. 删除跟进
curl -X DELETE http://localhost:8080/api/v1/customer/follow-records/1 -H "Authorization: Bearer $TOKEN"
```

## 12. 常见失败场景

| 场景 | 预期 |
|------|------|
| customerId 不存在 | "Customer not found" |
| opportunityId 不存在 | "Opportunity not found" |
| 商机不属于该客户 | "Opportunity does not belong to this customer" |
| followerId 不存在 | "Follower user not found" |
| customerIntention 超出1-4 | "Customer intention must be 1-4" |
