## 4. 核心类说明

### 4.1 CrmOpportunityServiceImpl
- **stage 管理**: DB 存 VARCHAR，API 传 Integer，内部 parseStage/getStageName 转换
- **stage 状态机**: 新增 1-4，/stage 1-4，/win → 5，/lose → 6
- **已关闭保护**: stage=5/6 时拒绝 /stage、/update、重复 /win、重复 /lose
- **删除**: LambdaUpdateWrapper 强制更新 deleted=1

### 4.2 OpportunityController
- 9 个端点分布在两个路径前缀：
  - `/api/v1/sales/opportunities/**` (8 个)
  - `/api/v1/customer/customers/{customerId}/opportunities` (OPP-009)

### 4.3 权限
- 复用 `CustomerPermissionInterceptor`（已有 ADMIN/SALES 检查）
- `/api/v1/sales/opportunities/**` 已加入拦截路径

## 7. 商机管理业务规则

- stage: 1初始接触/2需求确认/3方案报价/4商务谈判/5赢单/6输单
- 新增只能 1-4，不允许直接 5/6
- /stage 只能 1-4，不允许设 5/6
- /win: stage→5, probability→100, win_time=now, close_time=now
- /lose: stage→6, probability→0, lose_reason=必填, close_time=now
- 已关闭(stage 5/6)不可修改、不可阶段推进、不可重复赢/输
- ownerId 必填，校验存在+启用
- customerId 必填，校验存在+未删除
- amount ≥ 0
- probability 0-100

## 11. curl 测试命令

```bash
TOKEN="<admin-token>"

# 1. 先创建客户
curl -X POST http://localhost:8080/api/v1/customer/customers \
  -H "Content-Type: application/json" -H "Authorization: Bearer $TOKEN" \
  -d '{"customerName":"OppTest Corp","industry":"IT","ownerId":2,"status":1}'

# 2. 新增商机
curl -X POST http://localhost:8080/api/v1/sales/opportunities \
  -H "Content-Type: application/json" -H "Authorization: Bearer $TOKEN" \
  -d '{"customerId":1,"opportunityName":"CRM Project","amount":50000,"stage":1,"probability":20,"ownerId":2,"expectedDate":"2026-07-15"}'

# 3. 商机分页
curl "http://localhost:8080/api/v1/sales/opportunities?pageNo=1&pageSize=10" -H "Authorization: Bearer $TOKEN"

# 4. 商机详情
curl http://localhost:8080/api/v1/sales/opportunities/1 -H "Authorization: Bearer $TOKEN"

# 5. 推进阶段
curl -X PATCH http://localhost:8080/api/v1/sales/opportunities/1/stage \
  -H "Content-Type: application/json" -H "Authorization: Bearer $TOKEN" \
  -d '{"stage":2,"probability":40}'

# 6. 赢单
curl -X PATCH http://localhost:8080/api/v1/sales/opportunities/1/win \
  -H "Content-Type: application/json" -H "Authorization: Bearer $TOKEN" \
  -d '{"remark":"Client confirmed"}'

# 7. 按客户查商机
curl http://localhost:8080/api/v1/customer/customers/1/opportunities -H "Authorization: Bearer $TOKEN"

# 8. 删除商机
curl -X DELETE http://localhost:8080/api/v1/sales/opportunities/2 -H "Authorization: Bearer $TOKEN"
```

## 12. 常见失败场景

| 场景 | 预期 |
|------|------|
| customerId 不存在 | PARAM_ERROR "Customer not found" |
| ownerId 不存在 | PARAM_ERROR "Owner user not found" |
| 新增 stage=5 | PARAM_ERROR "Cannot create with stage 5 or 6" |
| /stage 设 5 或 6 | PARAM_ERROR "Cannot set stage to 5/6 via this endpoint" |
| 已赢单再 /stage | OPERATION_FAILED "Cannot advance a closed opportunity" |
| 已赢单再 /win | OPERATION_FAILED "Opportunity already won" |
| 已输单再 /lose | OPERATION_FAILED "Opportunity already lost" |
| /lose 无 loseReason | 400 参数校验 |
| amount 负数 | PARAM_ERROR "Amount cannot be negative" |
| probability 超出 0-100 | PARAM_ERROR |
