# 前端演示答辩脚本

> 完整演示时长：约 10-15 分钟

## 环境准备

```bash
# 1. 启动后端
cd E:\AI\Claude\WorkSystem
mvn spring-boot:run

# 2. 启动前端
cd E:\AI\Claude\WorkSystem\frontend
npm run dev
```

## 演示流程

### Step 1: 登录 (30s)

1. 打开 `http://localhost:5173`
2. 自动跳转登录页
3. 输入 admin / 123456
4. 点击登录 → 进入仪表盘
5. **讲解**: "系统支持 JWT Token 认证，登录后自动保存 Token，后续请求自动携带"

### Step 2: 系统管理 (2min)

1. 左侧菜单 → "用户管理"
   - 展示分页列表和筛选
   - **讲解**: "ADMIN 可以管理所有系统用户"
2. 点击"新增用户" → 填写信息 → 多选角色 → 提交
   - **讲解**: "新增用户时可以同时分配角色"
3. 点击某个用户 → "编辑" → 修改信息
4. 点击"启用/禁用" → 确认
5. 点击"分配角色" → 修改角色
6. 点击"重置密码" → 输入新密码
7. 点击"删除" → 显示后端规则保护
8. 左侧 → "角色管理"
   - 展示角色列表
   - **讲解**: "ADMIN 和 SALES 是内置角色，受后端保护不可删除"
9. 左侧 → "操作日志"
   - 展示操作记录
   - 点击"详情" → 展示 JSON 格式化的请求参数和响应
   - **讲解**: "所有写操作自动被 AOP 记录，密码和 Token 已脱敏"

### Step 3: CRM 业务流程 (5min)

1. **新建客户**: 客户管理 → 新增 → 填写"XX科技有限公司"
   - 行业：信息技术、来源：展会、等级：重要客户
   - 提交成功

2. **创建商机**: 点击"创建商机"按钮 → 填写商机名称"ERP系统采购"
   - 阶段：初步接触、金额：500000、概率：30%
   - 提交成功

3. **添加跟进**: 回到客户列表 → "添加跟进"
   - 跟进方式：电话、跟进内容：已联系对方IT负责人、客户意向：高
   - 提交成功

4. **阶段推进**: 进入商机管理 → 找到商机 → "推进" → 选择"需求确认" → 概率 50%
   - 再次推进 → "方案报价" → 概率 70%
   - 再次推进 → "商务谈判" → 概率 90%
   - **讲解**: "商机阶段从1到4逐步推进"

5. **赢单**: 点击"赢单" → 确认 → 商机变为赢单状态
   - **讲解**: "赢单是独立接口，stage=5"

6. **创建订单**: 赢单后"创建订单"按钮出现 → 点击 → 填写金额和支付方式
   - 提交 → 订单状态：待付款

7. **订单流转**: 
   - 付款 → 输入支付方式"银行转账" → 状态变为"已付款"
   - 发货 → 输入物流单号"SF1234567890" → 状态变为"已发货"
   - 完成 → 确认 → 状态变为"已完成"
   - **讲解**: "订单严格按 1→2→3→4 流转，终态不可逆"

8. **查看关联数据**:
   - 进入客户详情 → 展示关联的商机、跟进记录、订单
   - 进入商机详情 → 展示关联的跟进和订单
   - **讲解**: "客户和商机详情页都展示了关联数据"

### Step 4: 统计看板 (1min)

1. 点击"首页仪表盘"
   - 展示 8 个统计卡片
   - 展示客户趋势图、商机阶段饼图、订单状态饼图
   - 展示销售业绩排行
   - **讲解**: "刚才的操作已经在统计看板中体现"

2. 点击"数据统计"
   - 展示 6 个图表
   - 切换时间范围 → 图表更新
   - 切换按天/按月 → 趋势图粒度变化
   - **讲解**: "所有图表基于真实后端 analytics 接口"

### Step 5: 权限演示 (1min)

1. 点击"退出登录" → 确认
2. 点击快捷按钮 → sales01 / 123456 → 登录
3. 观察菜单：
   - 没有"系统管理"分组
   - 只有业务和统计菜单
   - **讲解**: "SALES 角色只能访问 CRM 业务功能"
4. 在浏览器地址栏手动输入 `/system/users` → 进入 403 页面
   - **讲解**: "前端路由守卫 + 后端接口校验，双重保护"

### Step 6: 总结 (30s)

- **技术栈**: Vue 3 + TypeScript + Element Plus + ECharts + Axios
- **接口**: 62 个后端接口全对接
- **页面**: 13 个页面（登录/仪表盘/统计/403/404 + 用户/角色/日志 + 客户/商机/跟进/订单）
- **角色**: ADMIN + SALES 双角色
- **安全**: JWT 认证 + 路由守卫 + 响应拦截 + 二次确认
- **业务闭环**: 客户 → 商机 → 跟进 → 赢单 → 订单 → 付款 → 发货 → 完成

## 备用演示素材

- 如需要演示输单流程：创建新商机 → 推进 → 输单 → 必填 loseReason
- 如需要演示订单取消：创建新订单 → 取消（仅 待付款/已付款 可取消）
- 如需要演示操作日志：完成写操作后立即打开操作日志查看记录
- 如需要演示空数据：在无数据的条件下访问统计页，观察 empty 状态
